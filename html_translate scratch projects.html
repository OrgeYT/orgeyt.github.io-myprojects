📋 Complete Translation Features

1

Full Block Literal & Operator Coverage

Translates text typed inside set-variable blocks (set [text] to [hello]), operator logic ((text) = [hello]), string joins, lists, speech, and ask prompts.

2

Safe Custom Block & Link Preservation

Parses custom block prototypes (define my_block %s) while preserving argument placeholders (%s, %n) and syncing argument reporter blocks inside definitions.

3

Smart SVG Vector Font Auto-Fitting

Vector text elements are translated line-by-line while calculating text width and automatically scaling down font size if the translated language requires more horizontal space.

4

Dropdown Dependency Syncing

Ensures that if a Sprite is translated, blocks like distance to, point towards, touching, and create clone of are automatically updated to prevent script breaking.
