Arrownese Translator

Translate between plain text and Arrownese arrows. Line breaks are supported in both directions.

      How to use this key

      1. Every character has a position number from 1 to 83. Find the position in the table.
      2. To encode (text → arrows): find the character’s position and use the arrow at that same position.
      3. To decode (arrows → text): find the arrow’s position and use the character at that same position.
      4. Capital letters have their own arrows (positions 58 to 83), so A and a are different symbols.
      5. The space is ↺ (position 31). Position 30 is ⤳, which means “blank or unknown”. It is not a real letter.
      6. Encoding a character that is not in the key gives ⤳. Decoding ⤳ or an arrow that is not in the key gives □.
      7. Line breaks are kept as they are in both directions. In Arrownese → Text, normal spaces are kept too.
