💡 How to use
Set a grid size and click Create Grid.
Select a color and brush size, then click or drag across the canvas to paint.
Classic supports grids from 1 × 1 to 35 × 35 and uses your original Scratch color codes.
Modern supports grids from 1 × 1 to 100 × 100 and adds 50 color codes using numbers, letters and symbols.
Save codes always use a comma, while both commas and periods can be loaded.
