⚠ CORRUPT MODE

This tool randomly changes bytes in the current emulator save state. It can cause glitches, freezes, crashes, or softlocks. There is no undo.

Corruption is applied to the middle of the save state (start and end headers are left alone) so the state is more likely to still load.

After this, a side panel will stay open so you can corrupt without popups.
