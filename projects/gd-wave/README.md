# Geometry Dash Wave Bot — GD Assets Edition

Recoded wave bot that uses real Geometry Dash assets and improved visuals while keeping the original wave physics.

## Features

- **Original wave physics** restored (triangle hitbox, exact ±45° motion)
- **Real GD sprites** for blocks, spikes (size varies by type), wave/dart + glow, and full-bleed background
- **Smooth visual tilt animation** when the wave changes direction (purely cosmetic, does not affect collision or bots)
- **GD-style trail** (fading short segments + spark dots)
- **Camera zoom** (edit + play):
  - Buttons in the panel
  - `+` / `-` keys
  - `Ctrl + Mouse Wheel`
  - `Ctrl + 0` to reset
- UI polish with GD-inspired green accents and light button animations

Serve the folder over HTTP and open `index.html`.
